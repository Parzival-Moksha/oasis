# Oasis Village

The Oasis is a 3D village that runs on your own machine. Each of your Claude Code sessions is a character there: you walk around, see who is working, who is waiting and who needs a decision, and talk to any of them by typing or by voice.

This plugin is the small way in. It adds one command and holds no code: only this README, a licence, an icon and the command's text.

## Install

```
/plugin install oasis-village --marketplace Parzival-Moksha/oasis-lite
```

## Use

```
/oasis-village:oasis          install (the first time) and open the village
/oasis-village:oasis status   what is running
/oasis-village:oasis stop     stop it
```

You need Node.js 20 or later and git.

## What the command does

The command is a page of instructions for Claude (`commands/oasis.md`). It tells Claude to run, with your approval in the usual permission prompt, these commands and no others:

- `node -e …` to find your home folder, and `node --version`.
- **The first time only, after asking you:** `git clone --depth 1 --branch v0.6.0 https://github.com/Parzival-Moksha/oasis-lite.git` into `~/.oasis/app`. That is the Oasis's source, about 30 MB, from this project's own public repository, at a fixed tag.
- `node ~/.oasis/app/scripts/oasis.mjs start` (or `status`, `stop`). The first start installs the Oasis's npm packages from its lockfile and builds it (a few minutes, once). Then it starts two servers on your machine, the page on `127.0.0.1:4516` and the agent engine on `127.0.0.1:4530`, and opens your browser.

The command does not tell Claude to read or follow instructions from what it downloads: the download is an application, not directions for Claude.

## What it sends and fetches

- **Fetches:** the one `git clone` above from github.com, the first time. The Oasis's start script then fetches its npm packages from the npm registry, as listed in its lockfile.
- **Sends:** nothing. This plugin has no hooks, no MCP server and no scripts.

## What the Oasis app does once it runs

- It reads your Claude Code session transcripts in `~/.claude/projects` to list your sessions and show their history, and runs the sessions you start in the village as ordinary `claude` processes under your own account. Permission prompts are shown to you; nothing is approved for you.
- Both servers listen on this machine only, and refuse requests without a local key the Oasis makes on its first start.
- Nothing is sent to the authors: no account, no telemetry.
- Agents can speak with your browser's built-in voices. No picture, video, music or speech is generated by an AI service unless you add your own key for one.

## The full plugin

This listing cannot make a session that runs in the desktop app or a terminal talkable from the village; that needs the full Oasis plugin, which is installed from the project's own marketplace:

```
/plugin marketplace add Parzival-Moksha/oasis-lite
/plugin install oasis@oasis
```
